# Dr. Saúde

ChatBot de atendimento de uma clínica, feito em Python para a disciplina de Desenvolvimento de Sistemas Computacionais para Processamento e Registro de Dados (UNIFAN).

Pelo menu o paciente pode marcar consulta, ver se o exame está pronto, conferir as consultas marcadas para o retorno e pegar o contato da recepção.

## Como rodar

```
python atv_fan_01.py
```

Para testar a retirada de exames, os protocolos prontos são 1001, 1002, 1005 e 1010.
